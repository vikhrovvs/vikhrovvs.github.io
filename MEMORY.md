# Память проекта

Этот файл — компактный контекст для новых чатов Codex. Здесь хранятся только подтверждённые и относительно устойчивые решения. Инструкции по работе находятся в `AGENTS.md`.

## Назначение

`vikhrovvs.github.io` — личная страница для небольших интерактивных проектов. Сейчас опубликованы:

- `/` — индекс проектов;
- `/anagrams/` — «Словограф», интерактивный граф русских анаграмм;
- `/word-route/` — «Словесный маршрут», daily-игра на том же графе.

Основной язык интерфейса — русский. Сайт должен работать как набор статических файлов на GitHub Pages, без серверного состояния.

## Структура

- `site/index.html`, `site/home.css` — главная страница и карточки проектов.
- `site/anagrams/` — граф, его интерфейс и данные.
- `site/word-route/` — игровая страница; загружает `../anagrams/data/graph.json` и не хранит копию данных.
- `scripts/build-data.mjs` — пересборка графа из частотного CSV DetCorpus.
- `scripts/check_site.py` — быстрая проверка структуры, локальных ссылок и инвариантов графа.
- `.github/workflows/pages.yml` — публикация содержимого `site/` через GitHub Pages.

Никакого шага production-сборки нет. Локальный сервер запускается командой `python3 -m http.server 4173 --directory site`.

## Данные и модель графа

`site/anagrams/data/graph.json` содержит около 20 тысяч русских лемм, объединённых в анаграммные вершины.

- Вершина объединяет слова с одинаковым мультимножеством букв.
- Представитель `label` — самое частотное слово; размер узла в графе зависит от суммарной `frequency`.
- Ребро `replace` означает замену одной буквы при одинаковой длине.
- Ребро `add` означает добавление или удаление одной буквы.
- Порядок букв не учитывается.

Исходные частоты — DetCorpus, ipm, CC0. Атрибуция находится в `THIRD_PARTY_NOTICES.md`. Исходные CSV не коммитятся, готовый `graph.json` коммитится.

## Словограф

- Canvas показывает локальное окружение выбранной вершины, поддерживает pan, zoom и мини-карту.
- В вершине постоянно видны все её анаграммы; менее частотные слова набраны мельче, но остаются внутри круга.
- Поиск существующего слова переводит к его вершине. Неизвестное слово временно добавляется в память страницы вместе с вычисленными рёбрами.
- Правая панель показывает состав вершины, частоты, соседей и поиск кратчайшего пути.
- Глубина окружения и лимит видимых вершин настраиваются.
- Прямая ссылка на выбранное слово использует `?word=...`.
- Левая колонка содержит рекордные группы по числу слов в узле и по длине слова со сменяемыми примерами.

## Словесный маршрут

- Один ход — переход к соседней вершине графа; карточка показывает все анаграммы вершины.
- Пользователь видит всех соседей на расстоянии один, текущий путь и может отменить либо обрезать путь до уже посещённой точки.
- Цель подсвечивается. Подсказка «Слово» показывает следующий узел одного из кратчайших путей от текущей позиции, а «Длина пути» — оставшееся минимальное число ходов.
- После финиша показываются число ходов, длина оптимального пути и один произвольный оптимальный путь.
- Daily-пара детерминированно выбирается по UTC-дате. Настраиваемые константы диапазона находятся в `site/word-route/app.js`; сейчас расстояние равно 3–5.
- Пользовательская пара задаётся параметрами `?from=...&to=...`.
- Случайная игра задаётся `?distance=X&seed=Y`; seed делает ссылку воспроизводимой. UI допускает расстояния 1–12.
- Backend, аккаунтов, таблицы рекордов и постоянной статистики пока нет.

## Продуктовые решения

- Игра — отдельный проект и URL, а не режим внутри Словографа. На главной у неё своя карточка; между проектами есть перекрёстные ссылки.
- Словарь и правила рёбер общие для графа и игры.
- Нетривиальные игровые механики — таймер, жизни, очки, streak и статистика — сначала обсуждаются, затем реализуются. Две подсказки («Слово» и «Длина пути») входят в текущие правила игры.
- Будущее хранение результатов потребует отдельного решения о backend, идентификации пользователей и приватности.

## Публикация и известные тонкости

- Push в `main` запускает GitHub Actions workflow и публикует папку `site/` на `https://vikhrovvs.github.io/`.
- CSS-классы с собственным `display` могут переопределить браузерное отображение атрибута `hidden`. В игровой таблице стилей есть глобальное `[hidden] { display: none !important; }`.
- GitHub Pages и браузер могут кешировать CSS/JS после deployment. Подключения изменяемых ассетов должны иметь версионный query-параметр, который увеличивается при изменении файла.
- Daily использует UTC, чтобы пара не зависела от часового пояса посетителя.
